# Customer_Behavior_Analysis
Data Analytics project showcasing customer behavior analysis using python,sql and power bi

# 📊 Data Analytics Project

## Overview

An end-to-end Data Analytics project covering data loading, cleaning, EDA, SQL analysis, Power BI visualization, reporting, and presentation.

## Dataset

The project uses a Customer Shopping Behavior dataset containing customer demographics, purchases, categories, ratings, discounts, payment methods, and purchase frequency.

## 🛠️ Tools

* Python & Pandas
* PostgreSQL 
* Power BI
* GitHub

## 🔄 Steps

1. Loaded the dataset using Python.
2. Performed EDA to understand patterns and trends.
3. Cleaned and prepared the data.
4. Performed SQL queries for analysis.
5. Built an interactive Power BI dashboard.
6. Created a project report.

## 📊 Dashboard

The Power BI dashboard presents:

* Customer and purchase analysis
* Category-wise performance
* Demographics
* Payment methods
* Subscription status
* Purchase frequency
* Seasonal trends

## 📈 Results

The analysis helped identify customer purchasing patterns, category performance, subscription behavior, payment preferences, and other business insights.

## ▶️ How to Run

```bash
pip install pandas matplotlib seaborn
```

Load the dataset in Python/Jupyter Notebook, perform the analysis, run the SQL queries in your database, and open the `.pbix` file in Power BI Desktop.
